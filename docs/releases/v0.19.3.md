### Before updating: check dosing automations

`chihiros.set_dosing_schedule` now rejects `weekdays` or `frequency` without `daily_ml`. Older versions accepted that combination but did not write the repetition to the pump. The old action editor could save `weekdays: [everyday]` by default.

- To update schedule points **without changing daily volume or repetition**, remove `weekdays` and `frequency` from the action. Do not add a dummy volume.
- To **change repetition**, include the intended `daily_ml` in the same action. With a daily volume, omitting the weekdays means every day.

The same rule applies to `chihirosctl dosing program` (`--weekdays` requires `--daily-ml`) and the Python pump client's `program_channel` (`frequency` requires `dose_per_day_ml`).

**Python library users with custom transports:** ordinary commands retain the previous `send` signature. For LED schedule changes, support the optional write boundary described in `docs/architecture.md`. Home Assistant and the built-in BLE transport need no transport migration.
